# Software Defect Prediction Using Machine Learning

## Overview

This project predicts software defects using machine learning techniques.

The objective is to classify software modules as defective or non-defective using software metrics.

## Machine Learning Workflow

- Data Preprocessing
- Exploratory Data Analysis
- Feature Scaling
- Model Training
- Model Evaluation

## Model Used

- Random Forest Classifier

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
