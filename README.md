# Software Defect Prediction Using Machine Learning

## Overview

Software defects can affect software reliability and quality. 
This project uses Machine Learning techniques to predict whether a software module is defective or non-defective based on software metrics.

## Objective

To develop a classification model that can automatically identify potential software defects and support software quality improvement.

## Dataset

The project uses a Software Defect Dataset containing software metrics and defect labels.

Dataset Details:
- Training Samples: 101,763
- Testing Samples: 67,842
- Type: Binary Classification

## Machine Learning Workflow

1. Data Loading
2. Exploratory Data Analysis
3. Data Preprocessing
4. Feature Scaling using StandardScaler
5. Model Training
6. Model Evaluation

## Machine Learning Models Used

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- XGBoost Classifier

## Best Performing Model

Random Forest Classifier was selected as the final model based on F1-score performance.

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC Score
- Confusion Matrix
